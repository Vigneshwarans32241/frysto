Demonstration of Port Scanning and Footprinting Date :

AIM

            To perform footprinting and port scanning on a target system using Nmap and identify the open
    ports and running services.

    Requirements
     Kali Linux

        Nmap

    Footprinting is the first phase of ethical hacking. It is the process of collecting information about a target
    system before performing penetration testing.
    Port scanning identifies open TCP/UDP ports and the services running on them.

    Procedure
    1. Boot Kali Linux.

    2. Open Terminal.

    3. Verify Nmap installation.

           nmap --version
    4. Scan the target host.

           nmap 192.168.1.10
    5. Perform service version detection.

           nmap -sV 192.168.1.10
    6. Perform OS detection.

          sudo nmap -O 192.168.1.10
    7. Record the open ports.


    Program / Commands
    Step 1: Verify Nmap Installation
            nmap --version
    Step 2: Scan a Target Host
            nmap 192.168.1.10
    Step 3: Scan Multiple Hosts
            nmap 192.168.1.10 192.168.1.15
    Step 4: Scan an Entire Network
            nmap 192.168.1.0/24
    Step 5: Perform a Ping Scan (Host Discovery)
            nmap -sn 192.168.1.0/24
    Step 6: Detect Service Versions
            nmap -sV 192.168.1.10
    Step 7: Detect Operating System
            sudo nmap -O 192.168.1.10
    Step 8: Perform Aggressive Scan
            sudo nmap -A 192.168.1.10
    Step 9: Scan Specific Ports

Auditing and Security Assessment Date :

    Aim
           To assess password strength using John the Ripper in a controlled laboratory environment.
    Requirements
        Kali Linux

          John the Ripper

        Password auditing checks whether passwords are weak, predictable, or vulnerable to offline cracking.
    Strong passwords improve system security.

    Procedure
       1. Open Terminal.

       2. Create password hash file.

                 unshadow passwd shadow > hashes.txt
       3. Execute John.

                  john hashes.txt
       4. Display cracked passwords.

                   john --show hashes.txt

    Program / Commands
    Step 1: Verify John the Ripper Installation
            john --version
    Step 2: Create a Password Hash File
            unshadow passwd shadow > hashes.txt
    Step 3: View the Contents of the Hash File
            cat hashes.txt
    Step 4: Perform Password Auditing
            john hashes.txt
    Step 5: Display Cracked Passwords
            john --show hashes.txt
    Step 6: Use a Dictionary File for Password Cracking
            john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt
    Step 7: Display Password Hash Information
            john --list=formats
    Step 8: Check Password Hash Type
            john --show --format=crypt hashes.txt
    Step 9: Save Cracked Passwords
            john --show hashes.txt > cracked_passwords.txt
    Step 10: View Saved Results
            cat cracked_passwords.txt
    Step 11: Remove Previous Session
            john --session=password_audit --restore
    Step 12: Display Help Menu
            john --help

    Aim
           To install and configure an Intrusion Detection and Prevention System for monitoring malicious
    network activities.
    Requirements
        Kali Linux

           Snort IDS

           Network Interface

             An Intrusion Detection System (IDS) monitors network traffic and detects suspicious activities. An
    Intrusion Prevention System (IPS) not only detects attacks but also blocks malicious traffic automatically.
    Snort is a popular open-source IDS/IPS used for real-time traffic analysis and packet logging.

    Procedure
       1. Install Snort (if not already installed).

        2. Configure the network interface.

        3. Verify Snort configuration.

        4. Start Snort in IDS mode.

        5. Generate sample network traffic.

        6. Observe alerts generated by Snort.


    Program / Commands
    Step 1: Verify Snort Installation
            snort -V

    Step 2: Display Snort Help Menu
            snort -?
    Step 3: Check Network Interfaces
            ip link show
    Step 4: Validate Snort Configuration File
            sudo snort -T -c /etc/snort/snort.conf
    Step 5: Start Snort in IDS Mode
            sudo snort -A console -q -c /etc/snort/snort.conf -i eth0
            Note: Replace eth0 with your active network interface (e.g., wlan0).
    Step 6: Start Snort with Packet Logging
            sudo snort -dev -l /var/log/snort -i eth0
    Step 7: Capture Network Traffic
            sudo snort -v -i eth0
    Step 8: Display Packet Headers Only
            sudo snort -d -i eth0
    Step 9: Display Complete Packet Information
            sudo snort -X -i eth0
    Step 10: Display Snort Alert Log
            cat /var/log/snort/alert
